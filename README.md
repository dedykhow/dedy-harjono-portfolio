# Portfolio Dedy Harjono

Website portfolio satu halaman berbahasa Indonesia.

## Preview lokal
Buka `index.html` menggunakan browser.

## Publikasi gratis dengan GitHub Pages
1. Buat repository GitHub baru, misalnya `dedy-harjono-portfolio`.
2. Atur repository menjadi **Public**.
3. Upload `index.html` dan file `README.md` ini ke root repository.
4. Buka **Settings → Pages**.
5. Pada **Build and deployment**, pilih **Deploy from a branch**.
6. Pilih branch `main` dan folder `/ (root)`, lalu klik **Save**.
7. Tunggu proses publikasi. URL biasanya berbentuk `https://USERNAME.github.io/NAMA-REPOSITORY/`.

Catatan:
- Semua tautan proyek mengarah ke layanan eksternal (Google Sheets, Looker Studio, GitHub, dan Streamlit).
- Demo Streamlit gratis dapat masuk mode sleep saat tidak aktif.
- Periksa kembali nomor telepon dan email sebelum mempublikasikan website.
